## 🎯 Choose Your Method

### **Method 1: Simplest (Windows Only)**
**Double-click this file:**
```
run-dev.bat
```
That's it! Your project will start at http://localhost:3000

---

### **Method 2: Command Line (Windows/Mac/Linux)**

Open your terminal in the project directory and run:
```bash
npm run dev
```

The dev server will start at **http://localhost:3000** ✅

---

### **Method 3: Node Script (Windows/Mac/Linux)**
```bash
node dev.js
```

This runs the full setup + starts the server with nice formatting.

## 💡 Need Help?

1. **Server won't start?**
   - Check port 3000 is free
   - Try: `npm run dev -- --port 3001`

2. **Page not loading?**
   - Refresh the browser (F5)
   - Check terminal for errors

3. **Want to stop the server?**
   - Press: `Ctrl + C`
