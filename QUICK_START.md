# 🚀 Quick Start Guide

## TL;DR - Get Started in 2 Minutes

### Step 1: Create Folders (in VS Code)
1. Right-click `app` → New Folder → `services`
2. Right-click `services` → New Folder → `ai-engineering`
3. Right-click `services` → New Folder → `data-science`
4. Right-click `services` → New Folder → `data-engineering`

### Step 2: Move Files
1. Right-click `_ai-engineering.page.tsx` → Cut
2. Open `app/services/ai-engineering/` → Paste
3. Rename file to `page.tsx` (remove underscore)
4. Repeat for other two files

### Step 3: Run & Test
```bash
npm run dev
```
Open http://localhost:3000 and click "Learn more" buttons!
